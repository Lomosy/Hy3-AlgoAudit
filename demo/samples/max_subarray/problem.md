# 最大子数组和

## 题目描述

给定一个长度为 $n$ 的整数数组 $a_1, a_2, \ldots, a_n$（元素**可以为负**），请找出一个**非空连续子数组**，使其元素之和最大，输出这个最大和。

## 输入格式

第一行一个整数 $n$。
第二行 $n$ 个整数 $a_1, a_2, \ldots, a_n$。

## 输出格式

一行一个整数，表示最大子数组和。

## 数据范围

- $1 \le n \le 10^5$
- $-10^9 \le a_i \le 10^9$

## 样例

输入：
```
5
-2 1 -3 4 -1
```
输出：
```
4
```
（子数组 [4, -1] 或 [4] 达到最大和 4；注意元素可以为负，且子数组不能为空。）
